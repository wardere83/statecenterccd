# statecenterccd

State Center Community College District — **FIT 2.0 (Faculty in Training) Program** dashboard.

2026–2028 EEO Innovative Best Practices Grant · $150,000 · Tier 2. A pre-hiring
faculty internship pipeline that recruits, mentors, and prepares diverse future
faculty across the District's four colleges: Fresno City, Reedley, Clovis, and Madera.
